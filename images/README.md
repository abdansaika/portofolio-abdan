# Portfolio image assets

Replace these filenames with your own images:

- `profile-full.png` — full-body portrait; vertical crop, preferably transparent background.
- `profile-main.png` — large cutout portrait; transparent PNG recommended for the red sticker outline.
- `face-illustration.png` — small portrait illustration for the hero.
- `project-1.jpg`, `project-2.jpg`, `project-3.jpg` — project images for the printed-photo frames.
- `canva-icon.webp`, `figma-icon.webp`, `pixellab-icon.webp`, `alight-motion-icon.webp` — official app listing icons used in the Skills grid.

The page includes CSS-drawn fallback artwork, so all sections remain visible before these files are added.
